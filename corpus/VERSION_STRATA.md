# Diagnosis rate by Minecraft version

Generated by `tools/version_strata.py` over 661 reports. Overall 396/661 = 59.9%.

A stratum is quotable as a rate at n >= 30; below that the Wilson interval is too wide to publish a number, so the interval is shown and the rate is not. The roadmap failure criterion is an adjacent-version gap above 20pp **with disjoint intervals** -- a gap between overlapping intervals is noise.

Three things about this corpus shape the table:

1. `(no version line)` is a *shape* stratum, not a release: Bedrock logs and issue bodies that are not crash reports have no `Minecraft Version:` line. It is reported and never chained into the adjacency test.
2. `26.1`/`26.2`/`26.3` are real -- Minecraft moved off `1.x` (`Minecraft Version: 26.1.2 (Tiny Takeover)`). An analysis filtering on a `1.` prefix drops 22 reports without saying so.
3. `(unparsed) 19w34a` is a snapshot id. Snapshots are listed verbatim and not merged into a release stratum; they are not releases.
