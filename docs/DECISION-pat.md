## 卡的是什么

`1E.1 可计分样本扩容 7 → ≥40` 需要持续 harvest 带明确维护者结论的 issue，匿名
GitHub API 配额 60 次/小时，不够；带 token 是 5000 次/小时。

现状：可计分样本 **7 份**，甩锅率 1/7 = 14%，Wilson 95% 区间 **[2.6%, 51.3%]**。
`corpus/blind-eval.json` 的 `ci95.quotable_as_rate.blame_error = false`——
机器已经拒绝把这个数当比率引用。

## 共同点（两条分支都一样）

1. **都不阻塞发布**。"1C.2 前置 1E"这条自设门可以降级为"发布时不得引用 n<30 的
   比率"——这条规则机器能查，人不用记。
2. **都不阻塞 Pack Doctor / 真实 jar / 3 条新规则**，那些是纯工时。
