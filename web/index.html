▣ mc-crash-doctor

粘贴 Minecraft 崩溃报告或服务器日志 → 直接给出根因、修复步骤，以及该找哪个模组算账。

🔒 纯本地运行。 日志不会离开你的浏览器。

贴完整报告效果最好——Mod List 和 System Details 能让定责准确很多。 也可以把 .txt/.log 文件拖进这个框，或点「选择文件…」。
